Kiunrhong
=========

Experimental color picker and utilities.

Naming
------

虹 (<em lang="hak-tw">kīung</em>, *rainbow*)、共樣 (<em lang="hak-tw">kīung rhōng</em>, *the same*) as in Taiwanese Hakka.
